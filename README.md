# 🎙️ AI VOICE ASSISTANT

An AI-powered voice assistant web application that enables users to interact using both **text and voice**.  
The assistant can answer queries, speak responses aloud, maintain chat history, and provide secure authentication with email OTP verification.

# ✨ Features

## 🔐 Authentication System
- User Registration & Login
- Email OTP Verification
- JWT-Based Authentication
- Secure Password Hashing

## 🤖 AI Assistant
- AI-Powered Conversations
- Real-Time Text Responses
- Groq API Integration
- Context-Based Chat Interaction

## 🎤 Voice Features
- Speech-to-Text Input
- AI Voice Responses
- Browser Speech Recognition
- Text-to-Speech Support

## 💬 Chat Management
- Persistent Chat History
- Create New Conversations
- Delete Chat History
- Collapsible Sidebar

## 🎨 Modern UI
- Responsive Dark Theme
- ChatGPT-Inspired Interface
- Clean & Minimal Design
- Fully Interactive Layout

## 🛡️ Security & Guardrails
- Offensive Query Filtering
- Harmful Prompt Detection
- Protected Routes
- Secure Authentication Flow

- Terrorism
- Harmful Requests
